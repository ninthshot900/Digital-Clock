왜 Chrome 메뉴에 [홈 화면에 추가]가 안 보이나요?
스마트폰에 다운로드한 로컬 파일(file:// 또는 content://)을 바로 열면, 모바일 Chrome 보안 정책상 [홈 화면에 추가] 메뉴와 일부 전체화면 API가 비활성화됩니다.
  1. 가장 깔끔한 해결책 (30초 무료 PWA 배포): 함께 제공된 digital_clock_pwa_package.zip 압축을 풀어 Netlify Drop (app.netlify.com/drop) 또는 GitHub Pages에 올리면 전용 https:// 주소가 생성됩니다.
  2. 그 주소를 공기계 Chrome으로 열면 메뉴에 [앱 설치 / 홈 화면에 추가]가 나타나며, 바탕화면 아이콘 실행 시 상단 주소창이 100% 제거된 가로 전체화면 앱으로 즉시 작동합니다.
  3. 로컬 파일 상태에서 바로 쓰실 때에는 시계 배경을 더블탭(두 번 연속 터치)하시면 주소창을 가리는 전체화면 모드가 실행됩니다.
